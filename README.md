## 🚀 Quickstart & Development

### 1. Install & Run Locally
```bash
cd degencheck-web3
npm install
npm run dev
```

### 2. Production Build
```bash
npm run build
npm run preview
```

### 3. Deploy to Vercel in 60 Seconds ($0 Hosting Cost)
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial DegenCheck release"
   gh repo create degencheck --public --push --source=.
   ```
2. Import repository into [Vercel](https://vercel.com) or [Cloudflare Pages](https://pages.cloudflare.com).
3. Framework Preset: **Vite**.
4. Build Command: `npm run build`
5. Output Directory: `dist`
